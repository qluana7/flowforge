# Flowforge

사용자가 자원, 부가 지표, 기계와 레시피를 정의하고 생산 공정을 연결해 정상 상태
생산량을 계산하는 Deno + TypeScript 웹 데모입니다.

## 웹 데모

<https://qluana7.github.io/flowforge/>

`main` 브랜치에 변경 사항이 올라오면 GitHub Actions가 검사와 테스트를 수행하고
GitHub Pages에 자동으로 배포합니다.

## 실행

```sh
deno task start
```

브라우저에서 <http://localhost:8000>을 엽니다.

개발 중에는 파일 변경을 감시하는 작업을 사용할 수 있습니다.

```sh
deno task dev
```

## 검증

```sh
deno task check
deno test
```

## 현재 포함된 기능

- UI에서 자원과 단위, 사용자 정의 부가 지표 생성
- 자원과 기계의 선택 이미지 등록 및 기본 이미지 복원
- 고유 ID를 사용하는 다중 입출력 레시피와 기계별 여러 레시피 등록
- 레시피 출력별 선택적 확률 모드와 기댓값 기반 계산
- 기계 노드의 단일/멀티 레시피 모드 선택
- 무한 공급 Resource Node와 여러 유한 자원을 공급하는 Input Node
- 기계, Resource, Input, 비율 분배, 병합 노드 드래그 앤 드롭
- 입력 또는 출력 어느 포트에서든 시작하는 연결 방식
- 연결 중 마우스를 따라가는 미리보기 선과 호환 포트 강조
- 자원 ID가 일치하지 않는 연결 차단
- 입력 포트당 단일 연결과 명시적인 병합 노드
- 출력 포트 더블 클릭을 통한 최종 출력 지정과 직접 산출량 집계
- 노드 이동, 설정 변경, 삭제
- Input Node별 최종 산출, 미처리 잔여 자원과 부가 지표 계산
- 폐쇄 루프 자동 감지, 초기 충전량·종료 시 순환 재고·루프 경로 분리 표시
- 순환 재고량에 따른 반복 실행과 동시 공정 처리 시간·병목 변화 반영
- Extract/최종 산출과 폐쇄 루프 순환 재고를 제외한 일반 잔여량이 0이 되는
  최소 입력 배치 역산 및 결과 즉시 적용
- 재료 도착과 기계별 실행 시간을 반영한 동시 공정 스케줄링
- 기계별 가동률·재료 대기 시간과 주요 병목 구간 판정
- 기본 다크 모드 및 라이트 모드 전환
- 한국어·영어 UI 전환 및 선택 언어 브라우저 저장
- 전체 화면 중심 공정 캔버스와 아이콘 기반 라이브러리 드로어
- 단일 노드 선택 시에만 표시되는 플로팅 인스펙터
- 가운데 마우스 버튼 드래그를 통한 캔버스 이동
- 음수 좌표를 포함해 모든 방향으로 제한 없이 배치 가능한 무한 캔버스
- 빈 캔버스 좌클릭 드래그를 통한 영역 다중 선택
- 선택한 여러 노드의 동시 이동 및 삭제
- 포트를 누른 채 반대 포트에 놓는 드래그 연결
- 최대 60단계 실행 취소/다시 실행과 키보드 단축키
- 자원·부가 지표·기계·레시피 삭제와 의존 항목 자동 정리
- 자원·부가 지표·기계·레시피 편집과 유효하지 않은 연결 자동 정리
- 35%~200% 캔버스 확대·축소
- 브라우저 로컬 저장 및 완전히 빈 새 프로젝트 생성
- 이름을 가진 프로젝트 JSON의 열기, 저장, 다른 이름으로 저장
- 자원·부가 지표·기계·레시피만 담는 빈 차트용 템플릿 가져오기·내보내기
- 프로젝트와 템플릿 JSON의 캔버스 드래그 앤 드롭 가져오기

앱은 자원, 기계, 레시피, 노드가 없는 빈 프로젝트로 시작합니다. 왼쪽 위
`프로젝트 / 파일 / 편집 / 보기` 메뉴에서 새 프로젝트, 프로젝트 저장, 템플릿
작업, Undo/Redo, 테마와 배율 기능을 사용할 수 있습니다.

## 캔버스 조작

- 캔버스 이동: 마우스 가운데 버튼을 누른 채 드래그
- 다중 선택: 빈 공간에서 마우스 왼쪽 버튼을 누른 채 영역 드래그
- 선택 추가/해제: `Ctrl`, `Cmd` 또는 `Shift`를 누른 채 노드 클릭
- 연결: 입력 또는 출력 포트를 누른 채 호환되는 반대 포트에 놓기
- 최종 출력 지정/해제: 출력 포트를 더블 클릭
- 연결 교체: 이미 연결된 입력 포트에 새 연결을 놓으면 기존 연결 자동 교체
- 연결 삭제: 연결선을 클릭한 뒤 `×` 버튼 또는 `Delete`
- 확대·축소: 상단 `−/＋` 버튼 또는 `Ctrl/Cmd + 마우스 휠`
- 100% 배율: 배율 버튼 또는 `Ctrl/Cmd + 0`
- 키보드 확대·축소: `Ctrl/Cmd + +`, `Ctrl/Cmd + -`
- 실행 취소: `Ctrl/Cmd + Z`
- 다시 실행: `Ctrl/Cmd + Shift + Z` 또는 `Ctrl + Y`
- 프로젝트 열기: `Ctrl/Cmd + O`
- 프로젝트 저장: `Ctrl/Cmd + S`
- 다른 이름으로 저장: `Ctrl/Cmd + Shift + S`

## JSON 파일 형식

작업 파일은 프로젝트로 통합하고, 재사용할 정의 모음은 템플릿으로 분리합니다.

- 프로젝트 (`flowforge-project`, `*.flowforge.json`): 프로젝트 이름, 모든 정의,
  노드, 연결, 최종 출력 포트, 배치 좌표와 카메라 `x`, `y`, `zoom`
- 템플릿 (`flowforge-template`, `*.template.json`): 자원, 부가 지표, 기계,
  레시피와 data URL 이미지만 포함하며 노드와 연결은 포함하지 않음

최초 `Ctrl/Cmd + S`에서는 운영체제 저장 창으로 이름과 위치를 지정합니다. 같은
브라우저 세션에서는 이후 동일한 파일에 바로 저장하며, 지원되는 브라우저에서는
파일 핸들을 기억해 다음 실행에도 재사용합니다. 직접 파일 쓰기를 지원하지 않는
브라우저에서는 JSON 다운로드 방식으로 대체됩니다.

템플릿을 불러오면 해당 정의를 사용하고 노드와 연결이 없는 새 플로우 차트를
만듭니다. 기존 `flowforge-definitions`와 `flowforge-chart` 파일은 마이그레이션을
위해 드래그 앤 드롭 가져오기를 계속 지원합니다. 참조가 누락되거나 ID가 중복되면
현재 프로젝트를 변경하지 않고 오류 목록을 표시합니다.

기본 흐름 계산 엔진은 `src/engine.ts`, 최소 배치와 병목 분석 엔진은
`src/analysis.ts`에 DOM 코드와 분리되어 있습니다.
